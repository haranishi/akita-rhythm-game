# 設計: 開発用のビルド経路だけを更新する

## 方針と理由

- Vite 7.3.6 → 7.3.7 のパッチ更新。Phaser 3.90.0・合成音・採点処理は保つ。
- Vite 開発サーバーへの要求が信頼境界。ファイル公開・エディター起動・ソースマップ処理の修正を、配信アプリの処理変更と切り離す。
- `postcss`・`nanoid`・`source-map-js` 等は親が許容する範囲内で、警告のあるものだけ更新する。親の範囲を無視する一括上書きは使わない。
- 検証は lockfile の版照合、クリーン導入、既存テストとビルド、ローカル HTTP 応答。未実施の実機試験や外部通信を成功と書かない。

## 見送った案

全依存の最新化は、ゲーム本体の互換性まで変更するため見送る。開発サーバーをインターネットへ公開しての検証は行わない。
