# 要件: 1ボタンのリズムゲーム「灯りの塔」の開発用依存を修正する

既存の振る舞いと受け入れ条件は `README.md` を引き継ぐ。今回の対象は依存経由の開発環境の保護。

1. GitHub が検出した Vite・PostCSS 周辺の脆弱な版を修正版へ更新する。
2. ゲームの処理・素材・実行時の直接依存を保つ。秘密情報や利用者データを検証へ使わない。
3. lockfile を固定してクリーン導入・既存テスト（ある場合）・本番ビルドを成功させる。
4. 未検証と修正版のない残件を記録し、警告の却下で完了扱いにしない。

## 範囲外

ゲーム機能追加、ルール調整、素材変更、外部ロビーや本番環境への接続。
