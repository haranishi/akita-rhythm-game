# 灯りの塔

秋田の夏の灯りを抽象化した、約36秒の1ボタン・リズムゲーム縦切り版です。既存の楽曲・録音・写真・キャラクターを使わず、図形とWeb Audio APIの合成音だけで作っています。

## ローカルで遊ぶ

前提はNode.js 20.19以上です。検証環境はNode.js 24.12.0、npm 11.6.2です。

```bash
cd /Users/hara/Projects/akita-rhythm-game
npm install
npm run dev
```

表示された`http://127.0.0.1:5173`をブラウザで開き、「ゲームを開始」を押します。操作は画面の「押す」またはSpaceです。音声自動再生の制約があるため、開始前には音が鳴りません。

一度`npm install`すれば、実行時にCDNや外部素材へ通信せず動作します。本体スピーカーまたは有線イヤホンを推奨します。Bluetooth利用時は入力補正を調整してください。

## テストとビルド

```bash
npm test
npm run build
npm run preview
```

`npm test`はbeat変換、時計変換、±35／80／130msの境界、入力補正、二重MISS防止を検証します。`npm run build`の出力は`dist/`です。

Phaserを一つのJSへ含めるため、ビルド時に500kB超の警告が出ます。gzip後は約337kBで、この縦切り版では遅延読込より単純さを優先しています。

## 今回の完成範囲

- Phaser 3の図形だけで描く1画面
- 生Web Audio APIを正本時計にした合成クリック
- PERFECT／GOOD／OK／MISS、スコア、コンボ、結果、再挑戦
- -150〜+150msの手動入力補正と端末内保存
- タブ非表示時の安全な中断
- PC／スマートフォン向けのレスポンシブ表示

ランキング、外部共有、3ゲーム化、自動キャリブレーション、正式な秋田文化モチーフは未実装です。
